# Canon: exempel och scenario

## Återkommande scenario

Boken använder den fiktiva myndigheten **Tullmyndigheten Atlantis** som återkommande scenario.

Atlantis är en större statlig tullmyndighet med ansvar för import, export, kontroll, riskanalys, ärendehandläggning, samverkan med andra myndigheter och digitala tjänster till externa aktörer.

## Återkommande verksamhetsområde

Det primära exempelområdet är **modernisering av importflödet**.

Exempelområdet används för att visa hur modellering kan stödja:

- verksamhetsförståelse,
- applikationsanalys,
- tekniska beroenden,
- mål och krav,
- förändringsinitiativ,
- vyer för olika målgrupper,
- bortval och avgränsning,
- införande av modellering som arbetssätt.

## Återkommande exempelbegrepp

| Typ | Namn | Användning |

| Förmåga | Hantera importdeklaration | Verksamhetsförmåga kopplad till importflödet. |
| Förmåga | Kontrollera varuflöden | Förmåga kopplad till risk, kontroll och regelefterlevnad. |
| Process | Granska importärende | Verksamhetsprocess för manuell eller stödd granskning. |
| Process | Besluta i importärende | Process där beslutsunderlag används. |

| Applikationskomponent | Ärendehanteringssystemet | Äldre men centralt system för ärendehantering. |
| Applikationskomponent | Riskanalysplattformen | Plattform för riskbedömning och prioritering. |
| Applikationstjänst | Riskbedöm importdeklaration | Applikationstjänst som stödjer kontrollprioritering. |
| Applikationsgränssnitt | Deklarations-API | Gränssnitt för externa ombud och deklaranter. |
| Teknikkomponent | Integrationsplattform | Teknik som kopplar samman applikationer och informationsflöden. |
| Mål | Snabbare och mer rättssäker importklarering | Strategiskt mål i Atlantis. |
| Krav | Spårbar beslutsmotivering | Krav som påverkar processer och applikationer. |

| Platå | Målarkitektur 2028 | Exempel på framtida arkitekturtillstånd. |

## Exempelprincip

Exemplen ska vara tillräckligt konkreta för att ge modellnytta, men inte så myndighetsspecifika att de kräver juridisk eller organisatorisk specialkunskap. Atlantis ska kännas som en trovärdig större myndighet, men vara tydligt fiktiv.
